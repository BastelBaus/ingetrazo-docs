# Keyboard shortcuts

Every button in the interface shows its shortcut on hover. The main ones:

## Drawing tools

| Key | Tool |
|:-:|---|
| `L` | Line |
| `R` | Rectangle |
| `K` | Rotated Rectangle |
| `C` | Circle |
| `A` | Arc (chord and bulge) |
| `J` | 3-Point Arc |
| `Shift+O` | Center Arc |
| `F` | Offset |
| `W` | Follow Me |

Polygon, Freehand, Pie and 3D Text have no key: they are in the Draw menu and on the toolbar.

## Editing

| Key | Tool |
|:-:|---|
| `Space` | Select |
| `Shift` + click | Toggle in the selection |
| `Ctrl` + click | Add to the selection |
| `Shift` + `Ctrl` + click | Remove from the selection |
| `M` | Move (`Ctrl` = copy; arrows = lock axis) |
| `Q` | Rotate (`Ctrl` = copy) |
| `S` | Scale (`Ctrl` = from the center; `Shift` = uniform) |
| `P` (or `U`) | Push / Pull |
| `E` | Eraser (`Shift` = hide the edge) |
| `B` | Paint (`Alt` = eyedropper) |
| `G` | Make Component… |
| `Ctrl+G` / `Ctrl+Shift+G` | Make Group / Explode |

Flip and Section Plane are in the Tools menu.

## Measuring and annotation

| Key | Tool |
|:-:|---|
| `T` | Tape Measure (guides) |
| `Shift+H` | Protractor |
| `D` | Dimension |
| `X` | Leader text |
| `Y` | Route (terrain) |

## Camera and view

| Key | Action |
|:-:|---|
| Middle button | Orbit |
| `Shift` + middle button | Pan |
| Wheel | Zoom |
| `O` / `H` | Orbit / Pan with the left button |
| `Z` | Drag zoom |
| `Shift+Z` (or `F2`) | Zoom Extents |
| `Shift+P` | Perspective ⁄ parallel |
| `Ctrl+0` | Clean screen |
| `↑` `→` `←` `↓` | Lock Z / X / Y axis · parallel or perpendicular to the reference (when drawing, moving, rotating and placing sections) |
| `↑` `→` `←` before the first click | Circle, polygon, rectangle and arcs: lock the drawing **plane** (XY / YZ / XZ); the same arrow releases it |
| `↓` before the first click | Circle, polygon, rectangle and arcs: plane **perpendicular to the edge** under the cursor (or parallel to the face), in magenta; `↓` again releases it |
| `Shift` | Freeze the current inference |

## General

| Key | Action |
|:-:|---|
| `Ctrl+Z` / `Ctrl+Shift+Z` (or `Ctrl+Y`) | Undo / Redo |
| `Ctrl+C` `Ctrl+V` `Ctrl+X` | Copy, paste, cut |
| `Ctrl+A` | Select all |
| `Del` | Delete the selection |
| `F2` | Rename (in the scene and layer lists) |
| `Esc` | Cancel the tool / leave the group |
| `Ctrl+N` `Ctrl+O` `Ctrl+S` | New, open, save |
| `Ctrl+Shift+A` | AI Assistant |
| `Ctrl+Shift+P` | Python Console |

## In the sheet composer

| Key | Action |
|:-:|---|
| `Ctrl` + wheel | Zoom on the sheet (wheel alone: scroll) |
| Middle button | Pan the sheet |
| Drag on empty sheet | Selection box (left → right: enclosed; right → left: touched) |
| `Shift` / `Ctrl` / `Shift+Ctrl` + click or box | Toggle / add / remove |
| Double-click a frame | Edit the view (`Shift` + drag rotates; `Enter`/`Esc` finishes) |
| Double-click a text | Edit in place (`Ctrl+Enter` confirms, `Esc` cancels) |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` `Ctrl+D` | Copy, cut, paste, duplicate items |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | Copy / paste style |
| `Ctrl+G` / `Ctrl+Shift+G` | Group / ungroup items |
| `Ctrl+L` | Lock / unlock |
| `Del` | Delete the selected item (or the selected guide) |
| `Esc` | Cancel a half-done placement (closes a dimension chain); with nothing half-done, leaves the tool |
| Arrows / `Shift`+arrows / `Alt`+arrows | Nudge the selection 1 mm / 10 mm / 0.1 mm |
| `Ctrl+Alt` + click | Select the item underneath (repeat to keep going down) |
| `Shift` while drawing a dimension, line or arrow | Lock the second point horizontal or vertical |
| Drag from a ruler | Pull a guide onto the sheet (back onto the ruler removes it) |
| `Ctrl+S` / `Ctrl+Shift+S` | Save the document from the composer |
