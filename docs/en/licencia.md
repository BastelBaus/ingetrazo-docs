## Components

- Interface built with **Qt (PySide6)**.
- `.skp` importer based on **[OpenSKP](https://github.com/iamahsanmehmood/openskp)** (MIT), an open-source project IngeTrazo actively contributes to.
- Base map: tiles from the providers you choose (Esri, OpenStreetMap…), under their own terms; the DEM comes from open sources (AWS Terrain).
