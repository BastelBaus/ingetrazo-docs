# 단축키

인터페이스의 모든 버튼은 마우스를 올리면 단축키를 보여 줍니다. 주요 단축키:

## 그리기 도구

| 키 | 도구 |
|:-:|---|
| `L` | 선 |
| `R` | 사각형 |
| `K` | 회전된 사각형 |
| `C` | 원 |
| `A` | 호 (현과 볼록 높이) |
| `J` | 3점 호 |
| `Shift+O` | 중심 호 |
| `F` | 간격 띄우기 (Offset) |
| `W` | 따라가기 (Follow me) |

다각형, 자유 곡선, 부채꼴, 3D 텍스트는 키가 없습니다: 그리기 메뉴와 도구 모음에 있습니다.

## 편집

| 키 | 도구 |
|:-:|---|
| `Space` | 선택 |
| `Shift` + 클릭 | 선택에서 토글 |
| `Ctrl` + 클릭 | 선택에 추가 |
| `Shift` + `Ctrl` + 클릭 | 선택에서 제거 |
| `M` | 이동 (`Ctrl` = 사본, 화살표 = 축 고정) |
| `Q` | 회전 (`Ctrl` = 사본) |
| `S` | 스케일 (`Ctrl` = 중심 기준, `Shift` = 균일) |
| `P` (또는 `U`) | 밀기 / 끌기 |
| `E` | 지우개 (`Shift` = 모서리 숨기기) |
| `B` | 페인트 (`Alt` = 스포이트) |
| `G` | 컴포넌트 만들기… |
| `Ctrl+G` / `Ctrl+Shift+G` | 그룹 만들기 / 그룹 분해 |

뒤집기와 단면 평면은 도구 메뉴에 있습니다.

## 측정과 주석

| 키 | 도구 |
|:-:|---|
| `T` | 줄자 (측정, 가이드) |
| `Shift+H` | 각도기 |
| `D` | 치수 |
| `X` | 지시선 텍스트 |
| `Y` | 경로 (지형) |

## 카메라와 뷰

| 키 | 동작 |
|:-:|---|
| 가운데 버튼 | 궤도 |
| `Shift` + 가운데 버튼 | 팬 |
| 휠 | 확대/축소 |
| `O` / `H` | 왼쪽 버튼으로 궤도 / 팬 |
| `Z` | 드래그 줌 |
| `Shift+Z` (또는 `F2`) | 전체 보기 |
| `Shift+P` | 원근 ⁄ 평행 |
| `Ctrl+0` | 깨끗한 화면 |
| `↑` `→` `←` `↓` | Z / X / Y 축 고정 · 기준에 평행 또는 수직 (그리기, 이동, 회전, 단면 배치 중) |
| 첫 클릭 전 `↑` `→` `←` | 원, 다각형, 사각형, 호: 그리기 **평면** 고정 (XY / YZ / XZ). 같은 화살표로 해제 |
| 첫 클릭 전 `↓` | 원, 다각형, 사각형, 호: 커서 아래 **모서리에 수직인** 평면(또는 면에 평행), 자홍색. `↓`를 다시 누르면 해제 |
| `Shift` | 현재 추론 고정 |

## 일반

| 키 | 동작 |
|:-:|---|
| `Ctrl+Z` / `Ctrl+Shift+Z` (또는 `Ctrl+Y`) | 실행 취소 / 다시 실행 |
| `Ctrl+C` `Ctrl+V` `Ctrl+X` | 복사, 붙여넣기, 잘라내기 |
| `Ctrl+A` | 모두 선택 |
| `Delete` | 선택 항목 지우기 |
| `F2` | 이름 바꾸기 (장면과 레이어 목록에서) |
| `Esc` | 도구 취소 / 그룹에서 나가기 |
| `Ctrl+N` `Ctrl+O` `Ctrl+S` | 새로 만들기, 열기, 저장 |
| `Ctrl+Shift+A` | AI 도우미 |
| `Ctrl+Shift+P` | Python 콘솔 |

## 시트 레이아웃에서

| 키 | 동작 |
|:-:|---|
| `Ctrl` + 휠 | 시트 확대/축소 (휠만: 스크롤) |
| 가운데 버튼 | 시트 팬 |
| 빈 시트에서 드래그 | 선택 상자 (왼쪽 → 오른쪽: 완전히 포함, 오른쪽 → 왼쪽: 닿는 것) |
| `Shift` / `Ctrl` / `Shift+Ctrl` + 클릭 또는 상자 | 토글 / 추가 / 제거 |
| 프레임 더블 클릭 | 뷰 편집 (`Shift` + 드래그로 회전, `Enter`/`Esc`로 끝) |
| 텍스트 더블 클릭 | 그 자리에서 편집 (`Ctrl+Enter` 확정, `Esc` 취소) |
| `Ctrl+C` `Ctrl+X` `Ctrl+V` `Ctrl+D` | 항목 복사, 잘라내기, 붙여넣기, 복제 |
| `Ctrl+Shift+C` / `Ctrl+Shift+V` | 스타일 복사 / 붙여넣기 |
| `Ctrl+G` / `Ctrl+Shift+G` | 항목 그룹화 / 그룹 해제 |
| `Ctrl+L` | 잠금 / 잠금 해제 |
| `Delete` | 선택한 항목(또는 선택한 가이드) 삭제 |
| `Esc` | 진행 중인 배치 취소 (연속 치수를 끝냄). 진행 중인 것이 없으면 도구에서 빠져나옴 |
| 화살표 / `Shift`+화살표 / `Alt`+화살표 | 선택을 1 mm / 10 mm / 0.1 mm 이동 |
| `Ctrl+Alt` + 클릭 | 아래에 있는 항목 선택 (반복하면 계속 아래로) |
| 치수, 선, 화살표를 그릴 때 `Shift` | 두 번째 점을 수평 또는 수직으로 고정 |
| 눈금자에서 드래그 | 시트로 가이드 끌어 내기 (눈금자로 되돌리면 삭제) |
| `Ctrl+S` / `Ctrl+Shift+S` | 레이아웃에서 문서 저장 |
