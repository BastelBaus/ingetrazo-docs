# 라이선스

**IngeTrazo는 자유 소프트웨어**이며, **GNU GPL-3.0 이상** 라이선스로 공개됩니다.

간단히 말하면:

- **사용**: 무료로, 어떤 용도로든 — 사무실의 상업적 작업도 포함. 계정도 제한도 없습니다.
- **연구**: 전체 소스 코드가 [GitHub](https://github.com/ingelibre/ingetrazo)에 있습니다.
- **공유**: 복사하고 배포할 수 있습니다.
- **개선**: 수정할 수 있습니다. 수정한 버전을 배포한다면 그것도 자유 소프트웨어(GPL)로 남아야 합니다.

IngeTrazo로 만든 모델, 시트, 내보낸 파일은 **여러분의 것**입니다 — 라이선스는 프로그램에 적용되며, 여러분의 결과물에는 적용되지 않습니다.

## 구성 요소

- 인터페이스는 **Qt (PySide6)**로 만들었습니다.
- `.skp` 가져오기는 IngeTrazo가 적극적으로 기여하는 오픈 소스 프로젝트 **[OpenSKP](https://github.com/iamahsanmehmood/openskp)**(MIT)를 기반으로 합니다.
- 기본 지도: 선택한 제공자(Esri, OpenStreetMap…)의 타일이며 각자의 약관을 따릅니다. DEM은 공개 소스(AWS Terrain)에서 옵니다.
