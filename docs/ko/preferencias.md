# 환경 설정

**창 ▸ 환경 설정…**에 프로그램 설정이 모여 있습니다. **확인**은 저장하고, **취소**는 아무것도 건드리지 않습니다. 거의 모든 것이 즉시 적용되며, 언어는 재시작이 필요합니다.

## 일반 { #general }

- **언어**: 스페인어, 영어, 브라질 포르투갈어(창 ▸ 언어에도 있음). 재시작 후 적용됩니다. 포르투갈어 시스템에서는 처음 실행할 때 포르투갈어로 시작하며, 아직 번역되지 않은 부분은 영어로 나옵니다.
- **편집 시 모델의 나머지**: 그룹에 들어갔을 때 나머지를 정상, **흐리게**, 또는 **숨기기**로. 카메라 ▸ 편집 시 모델의 나머지와 같습니다.
- **N분마다 자동 저장.** IngeTrazo는 문서의 백업을 데이터 폴더에 저장합니다(파일 옆에는 절대 저장하지 않음: 클라우드 동기화 디스크가 그런 곳의 쓰기를 잘라 먹은 적이 있습니다). 백업은 변경이 생긴 뒤 다음번 정상 저장까지만 존재합니다: 다음에 그 문서를 열 때 백업이 있다면 세션이 중단되었다는 뜻이고, 프로그램이 **복구를 제안합니다**. 마우스 버튼을 누르고 있는 동안에는 타이머가 동작하지 않습니다.
- **버린 자동 저장 백업 복구…**(파일 메뉴): 복구를 거절했다가 후회된다면, 버린 백업은 따로 보관되어 있어 여기서 열 수 있습니다.
- **이전 저장본의 백업 유지 (`.igz.bak`)**: 쓰기 전에 이전 파일을 옆에 `이름.igz.bak`으로 복사합니다. 잘린 저장(정전, 디스크 가득 참)이 좋은 버전까지 앗아 가는 일은 없습니다.
- **확대/축소 시 마우스 휠 방향 반전.**
- **안티에일리어싱 (MSAA)**: 샘플 0, 2, 4, 8개. 샘플이 많을수록 가장자리가 부드럽고 그래픽 카드의 일이 많아집니다.
- **실행 취소 단계**: 기록이 저장하는 작업 수(기본 200, 0 = 제한 없음). 단계마다 모델의 스냅숏이 들어가므로, 큰 모델에서는 메모리가 한도입니다. 즉시 적용됩니다.
- **단면 평면을 놓을 때 이름과 기호 묻기**: [단면 평면](modelado/secciones.md)을 놓을 때 나타나는 대화 상자를 «다시 묻지 않기»로 껐다면 다시 켭니다.

## 가져오기

- **OBJ 기본 단위**와 **DXF/DWG 기본 단위**: 가져올 때 단위를 묻는 대화 상자에 미리 선택될 답입니다(대화 상자는 계속 묻습니다: CAD 헤더는 틀린 경우가 많고, IngeTrazo는 **도면을 측정해서** 단위를 제안하기도 합니다).
- **좌표**: 지형 패널에 쓸 지리 좌표(위도/경도) 또는 UTM WGS84.

## 단위 { #unidades }

**지금 열린 문서의 단위**입니다 — 프로그램이 아니라 문서와 함께 저장됩니다. 길이 단위(미터, 센티미터, 밀리미터, 인치, 피트, 피트와 인치, 또는 분수형 `1 1/2"`)와 소수 자릿수를 고릅니다. 양방향으로 적용됩니다:

- **단위 없이** 입력한 숫자는 이 단위입니다: 밀리미터 문서에서 `2`는 2 mm이고, `2m`은 언제나 2 m입니다(명시한 단위가 우선).
- 프로그램이 **보여 주는** 모든 것 —도구, 개체 정보, 상태 표시줄, 재질별 요약— 이 이 단위로 읽힙니다.
- **치수 스타일**은 단위를 바꿀 때 따라가며, 그 뒤에는 자체 패널에서 따로 정할 수 있습니다.

새 문서는 미터로 시작하고, 0.4.9 이전 문서는 미터로 열립니다. 단위를 바꿔도 **형상은 바뀌지 않으며**, 읽고 입력하는 방식만 바뀝니다. 분수형에서는 **소수 자릿수**가 가장 작은 분모를 정합니다: 0 = 정수 인치, 1 = 1/4, 2 = 1/16, 3 = 1/32, 4 = 1/64.

## AI 도우미

[AI 도우미](ia.md)와 같은 항목들: 제공자, 키, 모델, Ollama URL, 그리고 뷰포트 캡처를 모델에 보낼지 여부.

## 프로그램이 알아서 기억하는 것

- **파일 ▸ 최근 파일 열기**: 마지막으로 열거나 저장한 `.igz` 문서 열 개와 «목록 지우기». 더 이상 없는 파일은 저절로 사라집니다. 가져오기(`.skp`, `.dxf`…)는 최근 문서로 치지 않습니다.
- **폴더**: 열기, 저장, 가져오기, 내보내기 대화 상자는 모두 그중 어디서든 **마지막으로 고른 폴더**에서 시작합니다(없으면 열린 문서의 폴더, 그것도 없으면 문서 폴더).
- 도구 모음과 패널의 **배치**.
- 레이아웃에서 마지막으로 편집한 치수의 **치수 스타일**, 그리고 기본 **표제란 템플릿**과 **시트 템플릿**.
- Windows에서 그래픽 카드가 두 개인 노트북(Intel + NVIDIA/AMD)이라면, 처음 실행할 때 시스템에 IngeTrazo용 **외장 그래픽**을 요청합니다. 뷰포트가 느리다면 **도움말 ▸ IngeTrazo 정보**가 어느 그래픽이 그리고 있는지 알려 주고, 소프트웨어 래스터라이저라면 경고합니다.
