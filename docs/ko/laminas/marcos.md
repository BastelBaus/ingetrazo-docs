# 뷰 프레임과 축척

**뷰 프레임**은 시트 위에 놓인, 모델로 난 창입니다. 레이아웃의 중심 항목입니다.

## 프레임 만들기

**프레임** 도구로 시트 위에 사각형을 그리거나(두 번 클릭 또는 드래그), 패널에서 **프레임 추가**를 누릅니다. 속성에서 고르는 것:

- **뷰**: 현재 카메라, **표준 뷰**(평면, 정면, 측면, 등각…), 또는 **저장된 장면** — 레이어, 단면, 스타일을 설정해 둔 «1층 평면» 장면이 곧 완성된 도면입니다.
- **축척 1:N**: 레이아웃의 절대 원칙 — *높이 200 mm 프레임에서 1:100은 모델의 정확히 20 m를 보여 줍니다*. 언제나, 근사 없이. 축척을 바꾸면 내용이 정확하게 다시 맞춰집니다. 콤보에 흔히 쓰는 축척이 있고, 다른 값도 받습니다.
- **확대 축척**: 작은 부재를 위해 콤보에 **2:1, 5:1, 10:1**도 있으며, 그렇게 입력해도 됩니다. 시트에는 그에 맞게 표기되고(«ESC. 10:1»), 표제란의 `{escala}` 필드도 마찬가지입니다.
- **프레임 크기**(mm), 끌거나 숫자로. **모델 맞춤**은 뷰를 모델 전체의 가운데에 맞춥니다.
- 프레임의 **인쇄 테두리**: 두께와 색, 또는 없음.

## 프레임 안의 뷰 편집

프레임을 **더블 클릭**하면 뷰 편집으로 들어갑니다: 프레임이 강조되고 마우스가 모델러에서처럼 그 **안에서** 동작합니다 —끌어서 구도 잡기, 가운데 버튼이나 `Ctrl`+드래그로 궤도, 휠로 줌— `Enter`, `Esc`, 또는 바깥 클릭까지. 동작 하나하나가 실행 취소 한 단계이며, 시트를 스크롤해도 프레임은 편집 상태를 유지합니다. 이렇게 손으로 맞춘 구도는 고른 뷰 소스에 속합니다: 프레임을 다른 장면이나 표준 뷰로 바꾸면 버려지고, 프레임은 그 장면의 카메라에서 다시 시작합니다.

**뷰 돌리기**: `Shift`+드래그는 프레임 안의 그림을 중심 기준으로 돌리며, 15°마다 자석처럼 붙습니다. 또는 패널의 **뷰 회전**에 각도를 입력합니다(양수 = 시계 방향, 방위표에 주는 것과 같은 각도). 프레임과 다른 모든 것은 그대로이고, 카메라에서 나오는 것이 돕니다: 렌더, 숨은선, 자석, 고정된 치수, 단면 표시, DXF.

## 렌더 스타일

| 스타일 | 보여 주는 것 |
|---|---|
| **모델 스타일** | 뷰포트에 보이는 그대로의 모델: 재질, 텍스처, 음영, 그림자. |
| **저장된 스타일** | 라이브러리의 아무 스타일(숨은선, 건축, X-ray, 내가 만든 것…)을 프레임별로. **새 프레임은 건축 스타일로 시작합니다**: 흰 배경, 모서리와 프로파일. |
| **벡터 (숨은선 제거)** | 제도사가 잉크로 그릴 그림: **숨은선을 정확한 계산으로 제거**하며, PDF와 DXF에 실제 벡터로 들어갑니다. |

스타일 아래의 **종이 배경** 체크박스는 스타일의 배경과 상관없이 하늘이나 지면 없이 흰 바탕에 렌더링합니다: **X-ray**(철근을 보여 줄 때)나 기본 스타일의 프레임도 모델의 회색을 시트로 가져오지 않습니다.

### 벡터 스타일의 펜과 포셰 { #plumas-y-poche-del-estilo-vector }

벡터 스타일은 사무실 도면처럼 선마다 종류를 나눠 그 펜으로 그립니다:

| 종류 | 기본 펜 | 무엇인가 |
|---|---|---|
| **단면 절단** | 0.50 mm | 단면 평면이 솔리드를 지나는 곳. |
| **프로파일** | 0.35 mm | 배경에 대한 실루엣과 윤곽(일반적인 프로파일 두께). |
| **모서리** | 0.18 mm | 보이는 두 면 사이의 나머지 모서리. |

단면이 **닫힌 솔리드**를 자르는 곳에서는 프레임이 절단면을 채웁니다(*포셰*): **솔리드** 또는 **45° 해칭**, 색과 해칭 간격은 원하는 대로. 열린 표면은 흰색으로 남습니다. 펜과 채움은 패널의 **벡터 펜** 섹션에서 조정하며, 이 섹션은 이 스타일에서만 나타납니다. DXF 내보내기는 종류를 `VISTA`, `VISTA-PERFIL`, `VISTA-CORTE` 레이어로 나눠 CAD의 펜 테이블에 맞춥니다.

## 뷰 제목

프레임 패널에서 **뷰 제목**을 켜고 스타일을 고릅니다:

- **번호, 밑줄**: 위에 뷰 **번호**, 아래에 **시트**가 있는 버블, 굵은 제목, «ESC. 1:N», 프레임 가장자리까지 이어지는 밑줄. 부제는 선택(«N.P.T. +0.15»).
- **세로 막대**: 프레임 왼쪽에 제목, 부제, 축척을 90° 돌린 띠와 아래쪽 버블 — 브라질 도면의 관행.
- **단순 선**: 익숙한 가운데 정렬 선.

제목, 부제, 번호, 시트에는 동적 필드를 쓸 수 있습니다: `{lamina}`는 표제란을, `{escala}`는 그 프레임의 축척을, `{escena}`는 장면 이름을 읽습니다. 정렬, 위치(아래 또는 위), 글자 크기도 같은 패널에 있습니다. 모두 뷰를 다시 계산하지 않고 실시간으로 편집됩니다.

## 단면 표시 { #marcas-de-seccion }

**단면 표시 (A–A)**를 켜면 프레임이 뷰를 지나는 모델의 각 단면 평면의 자취를 그립니다: 1점 쇄선의 절단선, 단면이 바라보는 쪽을 향한 화살표, 양 끝 버블 속 **평면 글자**. 그래서 평면도가 «단면 A-A»가 어디를 지나는지 알려 줍니다. 글자는 평면의 기호입니다([단면 평면](../modelado/secciones.md)). 기호가 없으면 순서대로 A, B, C…. 뷰에 평행한 평면은 표시를 남기지 않습니다.

## 프레임 추가 기능 { #extras-del-marco }

- **모델 주석**: 모델러에서 그린 치수와 지시선 텍스트가 고른 글자 높이로 프레임에 나옵니다.
- **선형과 측점**: 지형 위에 그린 [경로](../terreno/rutas-perfil.md)는 항상 뷰에 그려집니다(청록색, 노드 포함). **측점**을 켜면 평면 프레임이 정한 간격이나 자동 간격으로 이정 표시(0+000, 0+020…)를 붙입니다 — 시트의 지형 단면과 같은 간격이라 서로 일치합니다.
- **좌표 격자**: 뷰 위에 모델 미터 단위의 격자(격자 도면의 관행), 간격은 원하는 대로.
- **뷰 업데이트**는 현재 모델로 프레임을 다시 렌더링하고, **뷰 업데이트**(시트 도구 모음)는 전부를 다시 렌더링합니다. **자동 렌더링**(상태 표시줄)을 켜 두면 모델이 바뀔 때 프레임이 저절로 갱신됩니다 — 프레임은 캡처가 아니라 살아 있는 창입니다.

!!! tip "권장 흐름"
    모델러에서 **장면**을 준비하고(올바른 레이어와 단면을 갖춘 평면, 정면 입면) 레이아웃에서는 축척에 맞춰 놓기만 하세요. 프로젝트가 바뀌면 시트가 저절로 갱신됩니다.
