# PDF, 이미지, DXF 내보내기

모두 레이아웃 창 제목 아래의 **시트 도구 모음**에 있습니다: 미리 보기, PDF, 이미지. DXF는 프레임 메뉴에 있습니다.

## 인쇄 미리 보기

**인쇄 미리 보기…**는 시트를 나올 모습 그대로 보여 줍니다: 실제 크기, 선 두께, 핸들이나 자석 표시 없이. 내보내기 전에 검토하는 곳입니다.

## 시트 한 장의 PDF

**PDF 내보내기…**는 현재 시트를 정확한 물리 치수로 씁니다: A3는 A3로 나오고, 1:100 축척은 인쇄된 종이 위에서 1:100으로 **재어집니다**. PDF는 **벡터**입니다 — 벡터 스타일의 선은 픽셀이 아니라 세 가지 펜과 포셰를 갖춘 실제 곡선이라, 어떤 크기로 인쇄해도 선명합니다. 화면의 것은 아무것도 끼어들지 않습니다: 모델 선택도, 핸들도, 자석 표시도.

## 시트 한 장의 PNG 또는 JPG

**이미지 내보내기…**는 현재 시트를 **PNG나 JPG**로 씁니다: 파일을 고른 뒤 인치당 도트 해상도를 고릅니다(기본 200, 마지막 값을 기억). 이미지는 정확한 용지 크기로 나오며 —가로 A3를 200 dpi로 하면 3307 × 2339 픽셀— 흰 배경에 PDF와 같은 렌더러로 그려져, 보고서, 메일, 발표에 바로 쓸 수 있습니다.

## 아틀라스: 모든 시트를 하나의 PDF로

**모든 시트 내보내기 (PDF)…**는 문서의 시트를 각자의 페이지(각자의 용지 크기)에 담은 파일 하나를 만듭니다 — 클릭 한 번으로 도서 전체 도면 세트.

## IngeCAD / AutoCAD로 DXF 보내기 { #dxf-hacia-ingecad-autocad }

프레임을 선택하고 **뷰를 DXF로 내보내기…**를 누르면 그 뷰의 벡터 그림(정확히 보이는 선, 모델 미터 단위, 뷰 회전 적용)을 DXF R12로 씁니다 — [IngeCAD](https://ingecad.org), AutoCAD, LibreCAD, QGIS로 열립니다. 선 종류는 펜 테이블에 맞게 `VISTA`, `VISTA-PERFIL`, `VISTA-CORTE` 레이어로 나뉩니다. 2D 상세를 익숙한 CAD에서 마무리하는 사람을 위한 다리입니다.

!!! tip "내보내기 전에"
    - 레이아웃을 연 채로 모델을 편집했다면 **프레임을 업데이트하세요**(또는 자동 렌더링을 켜 두세요).
    - **줌 100 %**(실제 용지 크기)나 미리 보기에서 검토하세요: 선 두께와 글자 크기가 인쇄될 모습 그대로 보입니다.
    - 네 개의 [예제](../primeros-pasos/ejemplos.md)에는 비교해 볼 수 있도록 시트의 PDF가 옆에 있습니다.
