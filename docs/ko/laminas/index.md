# 시트 구성

**시트 레이아웃**은 IngeTrazo를 떠나지 않고 모델을 인쇄 도면으로 바꿉니다 — QGIS 레이아웃 방식처럼: **정확한 축척의 모델 뷰**를 시트 위에 놓고, 치수를 넣고, 표제란을 달고, 벡터 PDF로 내보냅니다.

**상태 표시줄의 탭**(모델 | 시트 1 | … | `+`)에서 엽니다 — 시트를 클릭하면 열리고, `+`는 새 시트를 만들며, **모델**은 모델러로 돌아갑니다 — 또는 **파일 ▸ 시트 레이아웃…**에서 엽니다.

![양케 아치의 시트 D04를 연 시트 레이아웃: 눈금자, 시트 도구 모음, 캔버스, 디자인 패널.](../images/laminas.jpeg)


## 창

- **시트 도구 모음**(제목 아래, 아이콘): 문서 **저장**(`Ctrl+S`, 여기서도 가능), **뷰 업데이트**, **PDF 내보내기…**, **이미지 내보내기…**(PNG 또는 JPG), **인쇄 미리 보기…**.
- **가운데 캔버스**: 그림자와 여백이 있는 시트. 위와 왼쪽에 밀리미터 **눈금자**가 있습니다(줌을 따라가며 커서 위치를 표시하고, 여기서 [가이드](#reglas-y-guias)를 끌어 냅니다). 줌은 `Ctrl+휠`, 상태 표시줄 콤보(*시트에 맞춤*, *너비에 맞춤*, 백분율 — 100 %는 화면에서 **실제 용지 크기**), 또는 왼쪽 도구 모음의 모델 도구 두 가지로 합니다: **확대/축소**(누른 점을 중심으로 위로 끌면 확대, 아래로 끌면 축소. 한 번 클릭하면 한 단계 확대)와 **줌 창**(상자를 끌면 그 영역으로 뷰가 채워짐). **팬**은 휠, 가운데 버튼, 손 도구로 어떤 줌에서든 할 수 있습니다: 시트를 잃어버리는 일이 없습니다(항상 한 띠는 보임).
- **왼쪽 도구 모음**: 선택, 손, 서식 복사, 뷰 프레임, 텍스트, 지시선 레이블, 레벨, 상세 표시, 이미지, 표제란, 축척 막대, 방위표, 범례, 지형 단면, 선, 화살표, **지반선**, 사각형, 타원, 다각형, 치수, 연속 치수, 각도 치수. 각 도구는 항목 하나를 놓고 선택으로 돌아갑니다. **치수 도구는 활성 상태로 남아** 연이어 이어 그릴 수 있습니다(`Esc`나 커서로 빠져나옴).
- **오른쪽 패널**(크기 조절 가능, 약 480 px에 맞음): 시트 관리자, **요소** 목록, 선택한 항목의 속성. 쓰지 않는 섹션은 접힙니다.
- **상태 표시줄**: 같은 모델 | 시트 탭, **자동 렌더링** 체크박스, mm 좌표, 줌.

## 시트

- 크기 **A4부터 A0**, 가로 또는 세로, 여백 설정, 선택 사항인 **시트 테두리**(단선 또는 이중선, 두께와 색. 인쇄됨).
- **문서당 여러 시트**: `+`는 만들기, `⧉`는 복제(표제란과 여백을 이어받음 — 도서 전체의 스타일을 유지하기에 좋음), `−`는 삭제, *시트 번호 다시 매기기*는 표제란의 L-01, L-02…를 갱신합니다. 두 창 어디서든 상태 표시줄의 **시트 탭을 오른쪽 클릭**해도 같습니다: *이름 바꾸기*, *복제*(사본은 바로 뒤에), *삭제*, *새 시트*.
- **시트 템플릿**(**템플릿…** 버튼): 시트 —용지, 여백, 테두리, 표제란, 빈 프레임— 를 이름 있는 템플릿으로 저장하고, 그것으로 새 시트를 만들며, 모든 새 문서에 쓸 **기본값**을 정합니다. 템플릿은 사용자 폴더의 파일입니다(*템플릿 폴더 열기*): 복사해서 공유합니다.
- 모든 것이 자체 실행 취소와 함께 **`.igz` 안에** 저장됩니다: `Ctrl+S`나 시트 도구 모음의 저장 버튼은 모델과 시트를 포함한 문서 전체를 저장하고, 환경 설정의 **자동 저장**도 시트를 포함합니다. 한 번 구성하면, 모델을 고칠 때마다 다시 열고 다시 내보내기만 하면 됩니다 — 또는 **자동 렌더링**을 켜 두고 갱신되는 것을 지켜보세요.

## 항목

시트 위의 모든 것은 항목입니다: 끌어서 옮기거나(여백, 중심, 가이드, 다른 항목에 자석처럼 붙음) **화살표 키로** 옮기며(1 mm, `Shift` 10 mm, `Alt` 0.1 mm — 누를 때마다 실행 취소 한 단계), 모서리를 잡아 크기를 바꾸고(커서가 알려 줌), 패널에 속성이 있습니다. 텍스트를 **더블 클릭**하면 그 자리에서 편집하고, 프레임을 더블 클릭하면 뷰 편집으로 들어갑니다.

**여러 개 선택**: 빈 시트에서 상자를 끕니다 — 왼쪽에서 오른쪽은 **완전히 들어온 것**(파랑), 오른쪽에서 왼쪽은 **닿는 것**(초록 점선)을 선택합니다. `Shift`는 토글, `Ctrl`은 추가, `Shift+Ctrl`은 제거. 빈 시트를 클릭하면 선택이 해제됩니다.

**아래에 있는 것**: 항목이 다른 항목을 가릴 때(프레임의 축척 레이블 위에 놓인 제목) `Ctrl+Alt+클릭`은 아래 항목을 선택하고, 반복하면 계속 아래로 내려갑니다. 또는 오른쪽 클릭 ▸ **아래 항목 선택**. 패널의 **요소** 목록은 언제나 모든 항목에 닿습니다.

아무 항목이나 **오른쪽 클릭**하면:

- **맨 앞으로 / 앞으로 / 뒤로 / 맨 뒤로** — 쌓는 순서(배경 사각형을 그려 뒤로 보내고 그 위에 모두 올리기).
- **잠금**(`Ctrl+L`) — 항목은 보이지만 **마우스가 닿지 않습니다**: 클릭도 상자도 잡지 못하므로, 잠긴 프레임 위의 치수와 텍스트를 프레임을 건드리지 않고 편집할 수 있습니다. 유일한 출입구는 패널의 **요소** 목록입니다: 거기서 선택, 편집, 잠금 해제합니다. 자물쇠 아이콘으로 표시됩니다.
- **정렬** — 선택(항목 두 개 이상)을 맞추고 분배, **그룹화와 그룹 해제**(`Ctrl+G`, `Ctrl+Shift+G`. 그룹은 함께 끌림), **복제**(`Ctrl+D`). 이 버튼들이 있는 「정렬」 도구 모음은 기본적으로 숨겨져 있습니다. 도구 모음을 오른쪽 클릭하면 표시할 수 있습니다.
- 같은 종류의 항목 사이에서 **스타일 복사 / 스타일 붙여넣기**(`Ctrl+Shift+C` / `Ctrl+Shift+V`) — 그리고 도구 모음의 **서식 복사**: 기준 항목 클릭, 대상 클릭, `Esc`.

**클립보드**: `Ctrl+C`, `Ctrl+X`, `Ctrl+V`는 시트 안에서 항목을 복사하거나(붙여넣으면 5 mm 아래, 오른쪽에 놓임) **시트 사이에서** 복사합니다(같은 자리에 놓임). 복사한 프레임에 연결된 텍스트와 고정된 치수는 붙여넣은 프레임을 따라갑니다. **표제란도 복사됩니다**: 다른 시트에 붙여넣으면 그 시트의 표제란 자리를 차지합니다.

## 눈금자와 가이드 { #reglas-y-guias }

QGIS처럼: **위쪽 눈금자에서** 페이지 쪽으로 끌면 **세로 가이드**(파란 점선)가, 왼쪽 눈금자에서 끌면 가로 가이드가 생깁니다. 항목은 옮기거나 크기를 바꿀 때 **가이드에 자석처럼 붙습니다**. 가이드는 자기 축을 따라 미끄러집니다. 없애려면 눈금자로 다시 끌어 놓거나, 선택하고 `Delete`. 눈금자를 오른쪽 클릭 ▸ **모든 가이드 지우기**. 가이드는 시트와 함께 저장되며 인쇄되지 않습니다.

이어서 **[뷰 프레임과 축척](marcos.md)** — 레이아웃의 핵심입니다.
