# 인터페이스

IngeTrazo 창은 네 영역으로 이루어져 있습니다:

- **3D 뷰포트**(가운데): 주 작업 공간입니다. 모든 것을 모델 위에서 직접 그리고 편집합니다.
- **도구 모음**: 그리기, 편집, 카메라, 주석, 그리고 **스타일**, **그림자**, **치수 스타일** 드롭다운. 각 버튼 위에 마우스를 올리면 단축키가 표시됩니다. 원하는 곳으로 끌어다 놓을 수 있고, 프로그램이 배치를 기억합니다.
- **사이드 트레이**(오른쪽): 개체 정보, 레이어, 장면, 재질, 컴포넌트, BIM, 지형, 측량점. 패널별로 접을 수 있고 크기도 조절됩니다.
- **상태 표시줄**(아래): 왼쪽에는 **모델 | 시트 1 | 시트 2… | + 탭**이 있어 —AutoCAD의 Model/Layout 탭처럼— 클릭 한 번으로 모델과 각 시트를 오갑니다(`+`는 새 시트를 만듭니다). 가운데에는 활성 도구의 메시지, 오른쪽에는 도구, 좌표, **VCB**(치수 입력란), 그리고 — 프로젝트가 지리 참조되어 있다면 — UTM 좌표가 실시간으로 표시됩니다.

## 모델 탐색

| 동작 | 방법 |
|---|---|
| **궤도** | 마우스 가운데 버튼(드래그), 또는 궤도 도구(`O`)로 왼쪽 버튼 |
| **팬** | `Shift` + 가운데 버튼, 또는 팬 도구(`H`) |
| **확대/축소** | 마우스 휠(터치패드에서는 두 손가락), `Z`로 드래그 줌, 줌 창으로 영역 맞춤 |
| **전체 맞춤** | 전체 보기(`F2`, 또는 카메라 도구 모음) |
| **표준 뷰** | 카메라 메뉴 ▸ 표준 뷰: 위, 정면, 측면, 등각… |
| **원근 / 평행** | `Shift+P`로 투영 방식 전환 |
| **깨끗한 화면** | `Ctrl+0`으로 도구 모음과 패널을 숨기고, 다시 누르면 되돌립니다 |

!!! tip "VCB: 키보드로 정확한 치수 입력"
    그리는 중에 **숫자를 입력하고 Enter** — 입력란을 클릭할 필요가 없습니다. 3.50 m 선이라면: 선을 켜고, 시작점을 클릭하고, 방향을 잡은 뒤 `3.50`을 입력하고 Enter. 거리, 반지름, 각도, 변의 개수, 배율 등 거의 모든 도구에서 동작합니다. 미터, 센티미터, 인치, 피트를 받습니다([자세히](../modelado/dibujo.md#medidas-por-teclado-metros-centimetros-pulgadas-pies)).

## 다크 모드

인터페이스는 뷰포트와 패널이 부딪히지 않도록 항상 어두운 테마를 씁니다. **모델**이 어떻게 보일지(배경, 하늘, 모서리, 그림자)는 [스타일](../modelado/estilos-sombras.md)로 직접 정합니다.

## 언어와 환경 설정

창 ▸ 언어에서 스페인어, 영어, 브라질 포르투갈어 중에서 고릅니다(재시작 후 적용). **창 ▸ 환경 설정…**에 나머지가 모여 있습니다: 자동 저장, 백업, 마우스 휠, 안티에일리어싱, 실행 취소 단계, **문서 단위**, 가져올 때 제안할 단위, AI 도우미 — [환경 설정](../preferencias.md)을 참고하세요. 설명서 원문은 스페인어 메뉴 이름을 쓰며, 이 한국어판은 앱의 한국어 번역에 맞춘 이름을 씁니다.
