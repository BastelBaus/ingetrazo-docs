# 단면 평면

**단면 평면**은 안을 들여다보도록 모델을 자릅니다 — 창 높이에서 자른 집의 평면, 분수의 축을 지나는 단면, 기둥 속의 철근. 방식은 이렇습니다: 평면을 놓으면 모델이 실시간으로 잘리고, 시트는 절단면을 채움과 함께 그립니다.

## 평면 놓기

1. **도구 ▸ 단면 평면**(도구 모음에도 있음).
2. 커서를 모델 위로 움직이면, 평면이 아래 있는 면(또는 바닥)에 **저절로 맞춰집니다**.
3. 면과 상관없이 방향을 고정하려면: **화살표 키**로 축을 고정합니다 — `↑`는 수평 절단(Z 평면), `→`는 X 방향 수직, `←`는 Y 방향 수직, `↓`는 다시 면에 맞춤 — 그리고 `Shift`는 현재 추론을 고정합니다. 평면은 항상 카메라 쪽을 향합니다: 모델 앞에 놓으면 내 쪽에 있는 부분이 숨겨집니다.
4. **클릭**으로 놓습니다. **이름**과 **기호**(시트에 나올 글자: A, B…)를 묻습니다. 제안된 값을 그대로 써도 됩니다: 기호는 **다음 빈 글자**이므로 단면이 A, B, C… 순서로 나오고, 시트의 표시는 제도 규칙대로 «A … A»로 읽힙니다. 한 번도 바꾸지 않는다면 **«다시 묻지 않기»**를 켜세요: 평면이 기본 이름과 기호로 만들어집니다([환경 설정 ▸ 일반](../preferencias.md#general)에서 대화 상자를 다시 켤 수 있음). 평면을 놓으면 도구가 **끝나고** 선택으로 돌아갑니다.

나중에 바꾸려면 단면 평면을 오른쪽 클릭 ▸ **이름과 기호…**.

방금 놓은 평면은 **활성** 상태가 되어 즉시 자릅니다.

## 단면 다루기

- **컨텍스트당 활성 평면은 하나뿐.** 다른 평면을 놓으면 그것이 활성화되고 이전 것은 꺼집니다. 평면을 **더블 클릭**하면 활성 여부가 전환됩니다.
- 이동(`M`)과 회전(`Q`) 도구로 평면을 **옮기고 돌립니다**: 프레임을 잡으세요. 단면을 모델 속으로 «산책»시키는 방법입니다.
- 평면을 **오른쪽 클릭**: **반전**(반대쪽을 자름), **활성 절단**, **뷰 정렬**(카메라가 평면에 수직으로 섬 — 단면도의 구도).
- **`Delete`**로 지우고, `Ctrl+Z`로 되돌립니다.
- 축에 수직인 평면의 프레임은 **그 축의 색**(빨강, 초록, 파랑. 비스듬한 것은 회색)으로 그려져, 각 평면이 어디를 자르는지 한눈에 보입니다.
- **카메라 ▸ 단면 평면**은 평면 프레임을 보이거나 숨기고, **카메라 ▸ 단면 절단**은 아무것도 지우지 않고 절단을 켜고 끕니다.
- 평면이 솔리드를 지나는 모서리는 **굵게** 그려지며, 스타일이 절단면을 채울 수 있습니다(**단면 채움**, 색상 지정. [스타일 편집기](estilos-sombras.md)에서).
- 그리기와 선택 도구는 **절단으로 숨겨진 부분에 닿지 않습니다**: 보이는 것에만 붙고 보이는 것만 선택합니다.

## 단면, 장면, 시트

- **장면**마다 어떤 평면이 활성이었고 절단이 보였는지를 기억합니다: 1.20 m 수평 절단을 담은 «평면» 장면이 건축 평면도가 되고, «단면 A-A» 장면이 단면도가 됩니다.
- **시트 레이아웃**에서 그 장면을 보여 주는 프레임은 절단을 그립니다: **벡터** 스타일에서는 절단 모서리가 굵은 펜으로 그려지고 잘린 솔리드는 **포셰**(솔리드 또는 해칭)로 채워집니다 — [뷰 프레임](../laminas/marcos.md#plumas-y-poche-del-estilo-vector) 참고.
- **단면 표시**: 평면 프레임은 그것을 지나는 각 단면 평면의 자취를 화살표와 버블 속 평면 글자와 함께 그릴 수 있습니다 — 그래서 평면도가 «단면 A-A»가 어디를 지나는지 알려 줍니다([시트 주석](../laminas/marcos.md#marcas-de-seccion)).
- 평면은 `.igz`에 저장되어 문서와 함께 복원됩니다.

!!! tip "철근 보기"
    콘크리트 속 철근이나 설비를 검토하려면 단면 평면과 **카메라 ▸ 스타일 ▸ X-ray**를 함께 쓰세요: 절단이 정확한 위치를 보여 주고, X-ray가 면 너머로 나머지 철근을 보여 줍니다. 아치와 가로등 [예제](../primeros-pasos/ejemplos.md)가 바로 그 용도로 만들어졌습니다.
