# 스타일, 그림자, 화면

모델이 어떻게 보일지는 문서별, 장면별로 직접 정합니다: **스타일**은 면, 모서리, 하늘, 배경을 정하고, **그림자**는 현장의 태양을 원하는 시각에 두며, 깨끗한 화면은 모델만 남깁니다.

## 스타일

**카메라 ▸ 스타일**에서 문서의 활성 스타일을 바꿉니다. 기본 제공 스타일:

| 스타일 | 보여 주는 것 |
|---|---|
| **기본** | 재질과 텍스처가 입혀진 면, 모서리, 그라데이션 하늘. |
| **건축** | 흰 배경, 하늘 없음, 모서리와 프로파일: 시트 같은 모습. 레이아웃에서 새로 만드는 모든 뷰 프레임의 기본 스타일입니다. |
| **음영** | 색이 있는 면, 텍스처 없음. |
| **숨은선** | 선만, 흰 면: 기술 도면. |
| **단색** | 한 가지 톤의 면. |
| **와이어프레임** | 모서리만. |
| **X-ray** | 모두 반투명, 모서리는 항상 보임: 자르지 않고 안(철근, 배관)을 들여다볼 때. |

**카메라 ▸ 모서리**와 **카메라 ▸ 프로파일**은 활성 스타일의 모서리와 굵은 윤곽선을 켜고 끕니다.

### 스타일 편집기

도구 모음의 **스타일** 드롭다운은 편집기를 열어 활성 스타일을 **실시간으로** 편집합니다:

- 면 모드(음영, 숨은선, 단색, 와이어프레임, X-ray), 모서리, 프로파일, 하늘, **단면 채움**.
- 네 가지 색: 면의 앞면과 뒷면, **하늘**과 **지면** — 지평선 쪽으로 그라데이션이 들어갑니다. 현재 모드에서 보이지 않는 색도 편집할 수 있으며, 상태 표시줄이 그 색이 어디에 보일지 알려 줍니다.
- **스타일 저장…**은 이름을 붙여 **내 라이브러리**에 추가합니다(기본 제공 이름은 거부됩니다: 프리셋은 고정). **삭제**로 지웁니다.
- 저장한 스타일은 카메라 ▸ 스타일과 **레이아웃의 각 프레임** 스타일 콤보에 나타납니다 — 프레임마다 다른 스타일을 쓸 수 있습니다.
- **장면**마다 자기 스타일을 기억하고, `.igz`는 스타일 전체를 저장합니다: 문서가 내 라이브러리에 의존하지 않습니다.

## 실제 태양의 그림자

도구 모음의 **그림자** 드롭다운(그리고 **카메라 ▸ 그림자**)은 **태양의 실제 위치**로 계산한 그림자를 켭니다:

- **날짜**: 일과 월, 그리고 연중 슬라이더. **시각**은 하루 범위로 제한됩니다 — 현장과 날짜의 일출부터 일몰까지라서, 태양이 지평선 아래로 가는 일이 없습니다.
- 그림자의 **어둡기**와 **시간대**(경도에서 추정하며, 직접 지정할 수 있음).
- **현장**: 프로젝트가 [지리 참조](../terreno/ubicacion.md)되어 있으면 그 기준점, 아니면 아레키파. **위치 추가…**는 위치 찾기를 열고 기준점을 정합니다.
- **불투명도 70 % 미만의 유리는 그림자를 드리우지 않습니다**. 구멍 뚫린 텍스처(망, 나뭇잎)는 무늬대로 그림자를 드리우고, 「정면 고정」 인물은 태양을 향한 실루엣을 드리웁니다.
- 태양은 **면에 음영도 줍니다**(태양을 등진 면은 더 어둡게 보임). 지면은 그림자를 반투명한 덧칠처럼 받습니다.
- 그림자 설정은 문서에 저장되며 **레이아웃의 프레임도 그 설정으로 렌더링합니다**: 일조 시트가 바로 나옵니다.

!!! note "정확도"
    천문 계산은 검증되었습니다(춘분에 태양은 정동쪽에서 뜨고, 6월 아레키파에서는 북쪽 약 50° 높이로 지나갑니다). 보이는 것이 그 날짜와 시각의 실제 현장 일조입니다.

## 깨끗한 화면과 배치

- **창 ▸ 깨끗한 화면**(`Ctrl+0`)은 도구 모음과 패널을 숨기고 뷰포트만 남깁니다. `Ctrl+0`을 다시 누르면 되돌아옵니다.
- **배치를 기억합니다**: 도구 모음을 어디에 두었는지, 트레이의 어떤 패널을 열었고 크기가 얼마였는지가 다음 세션에 그대로 돌아옵니다.
- **스타일**, **그림자**, **치수 스타일** 패널은 도구 모음의 드롭다운이라 오른쪽 트레이를 차지하지 않습니다.
- **카메라 ▸ 편집 시 모델의 나머지**: 그룹에 들어갔을 때 나머지를 정상, **흐리게**(기본값), 또는 **숨기기**(무거운 모델에서 가장 빠른 모드)로 보여 줍니다. 환경 설정에도 있습니다.

## 이미지 내보내기

**파일 ▸ 내보내기 ▸ 이미지 (PNG / JPG)…**는 현재 스타일과 그림자로 뷰포트를 고해상도로 캡처해 저장합니다 — 선택 표시나 도구 표시는 빠집니다.
