# 형상 편집

## 밀기 / 끌기

**`P`**(또는 `U`) — 그림을 입체로 바꾸는 도구입니다. 면을 클릭하고, 움직이고, 거리를 입력하고 Enter.

![밀기/끌기 사용 중: 작은 건물에 부피가 생기고 VCB(오른쪽 아래)가 정확한 거리를 받습니다.](../images/modelado.jpeg)


- 솔리드의 면 위에서: 솔리드를 **두껍게 하거나 얇게** 합니다.
- 면 안에 그린 도형 위에서: 반대쪽 면에 닿으면 **개구부를 뚫습니다**.
- 면의 재질은 **형상과 함께 따라갑니다**: 칠한 면을 밀면 칠해진 입체가 됩니다.
- **컴포넌트 사본** 위에서 바깥쪽에서 밀면 정의를 편집합니다: 모든 사본이 똑같이 밀립니다(그 사본만 바꾸고 싶다면 먼저 오른쪽 클릭 ▸ **고유하게 만들기**).
- IngeTrazo는 밀기마다 검사합니다: 작업이 솔리드를 깨뜨리게 된다면 경고와 함께 **거부**합니다 — 모델을 망가뜨리지 않습니다.

## 선택

**Space**로 선택을 켭니다.

| 동작 | 하는 일 |
|---|---|
| 클릭 | 클릭한 것을 선택합니다. 면을 더블 클릭하면 면과 그 모서리를, 트리플 클릭하면 연결된 모든 것을 선택합니다. |
| 왼쪽 → 오른쪽 드래그 | **창**: 상자 안에 완전히 들어온 것만. |
| 오른쪽 → 왼쪽 드래그 | **교차**: 상자에 닿는 모든 것. |
| `Shift` + 클릭 | **토글**: 선택되어 있던 것은 빠지고, 아니던 것은 들어옵니다. 큰 선택에서 모서리나 면 하나를 빼는 방법입니다. |
| `Ctrl` + 클릭 | 항상 **추가**. |
| `Shift` + `Ctrl` + 클릭 | 항상 **제거**. |
| 빈 곳 클릭 | 선택을 비웁니다. 보조 키를 누르고 있으면 그대로 둡니다. |
| `Esc` | 모두 선택 해제. |

선택 상자도 같은 보조 키를 쓰며, 그룹, 컴포넌트, 가이드도 함께 잡습니다.

## 이동, 회전, 스케일, 뒤집기

| 도구 | 단축키 | 메모 |
|---|---|---|
| **이동** | `M` | 선택하고 끕니다. 거리를 입력합니다(세 축 이동은 `X;Y;Z`). 점, 모서리, 면, 그룹, 혼합 선택을 옮깁니다. 화살표 키로 축을 고정하고, `Ctrl`로 **사본**을 옮깁니다. 어느 뷰에서든 세 축(X, Y, Z, 각 축 색깔)과 다른 객체의 면에 자석처럼 붙습니다. |
| **회전** | `Q` | 각도기: 원판은 마우스를 올린 곳에서 추론한 평면에 따라 색이 바뀝니다. **화살표 키**나 `Shift`로 평면을 고정하고, 피벗 클릭, 기준 클릭, 각도를 끌거나 입력합니다. 15°마다 자석 눈금이 있습니다. `Ctrl`로 **사본**을 회전하고, 중심에서 끌면 접기 축을 정합니다. `3:12` 같은 경사도 받습니다. |
| **스케일** | `S` | 핸들이 있는 노란 상자: **꼭짓점** = 균일 스케일, **모서리** = 두 축, **면** = 한 축. 기준점은 반대편입니다. `Ctrl`이면 **중심**에서 스케일하고, `Shift`는 균일을 강제합니다. VCB에는 배율(`2`), 축별 배율(`1;2;1`), 단위가 붙은 절대 크기(`3m`, `2'`), 또는 **반전용 음수 배율**을 넣습니다. 놓은 뒤에 다시 입력할 수 있습니다. 떨어진 형상, 그룹, 컴포넌트, 이미지에 한꺼번에 쓸 수 있습니다. |
| **뒤집기** | — | 도구 ▸ 뒤집기: 선택 위에 빨강, 초록, 파랑 반투명 평면 세 개가 나타나고, 하나를 클릭하면 그 평면으로 대칭 반전합니다. `Ctrl`로 **사본**을 뒤집습니다. 컨텍스트 메뉴에도 있습니다. |

## 지우개, 측정, 확인

| 도구 | 단축키 | 메모 |
|---|---|---|
| **지우개** | `E` | 모서리 위를 클릭하거나 끕니다. 모서리를 지우면 그것에 의존하던 면도 사라집니다. **`Shift` + 지우개는** 지우는 대신 선을 **숨깁니다**. |
| **줄자** | `T` | 두 점 사이를 재고 보조 **가이드**를 만듭니다: 모서리에서 시작하면 평행 가이드, **축**(빨강·초록·파랑 축을 클릭, 빈 문서에서도 가능)에서 시작하면 입력한 거리만큼 떨어진 축에 평행한 가이드, **이름 있는 점**(끝점, 중심, 교점, 원점)에서 시작하면 출발점까지 점선 **선분이 달린 가이드 점**을 만듭니다. |
| **각도기** | `Shift+H` | 각도를 재고 각도 가이드를 만듭니다. |
| **가이드 지우기** | — | 편집 ▸ 가이드 지우기. 가이드가 할 일을 다 했을 때. |

## 분할

선이나 호 위에서 오른쪽 클릭 ▸ **분할…** 후 구간 수를 넣습니다:

- **선**은 N개의 같은 조각으로 나뉘며, 자르는 곳마다 붙잡을 수 있는 꼭짓점이 생깁니다.
- **호나 원**은 체인을 따라 재어 **독립된 호 N개**가 되며, 각각 따로 선택할 수 있습니다: 넷으로 나눈 원은 사분원 네 개입니다.
- 그 모서리에 접한 면은 깨지지 않고 새 꼭짓점을 받습니다.
- 모서리를 여러 개 선택하면 모두 나뉘고, `Ctrl+Z` 한 번으로 되돌립니다.

## 모서리 숨기기 { #ocultar-aristas }

여러 면으로 이루어진 표면을 아무것도 지우지 않고 이어진 것처럼 보이게 하려면:

- 모서리를 선택하고 **편집 ▸ 모서리 숨기기**(또는 오른쪽 클릭 ▸ 모서리 숨기기), 또는 `Shift`를 누른 채 지우개로 지나갑니다.
- **편집 ▸ 모든 모서리 숨김 해제**로 되돌립니다(지금 있는 컨텍스트의 모든 모서리: 그룹 밖이면 떨어진 모서리, 안이면 그룹의 모서리).
- 숨긴 모서리는 다시 보이게 할 때까지 클릭할 수 없습니다. 시트와 내보내기도 숨김을 따릅니다. **보기 ▸ 숨긴 형상**(또는 **숨긴 객체**)을 켜면 숨긴 것이 유령처럼 그려지고 다른 것처럼 **클릭하고 선택할 수 있습니다**. 보기를 끄면 선택에서 빠집니다.

## 그룹과 컴포넌트

- **그룹 만들기**(`Ctrl+G`): 선택이 그룹이 됩니다 — 나머지와 «붙지» 않는 독립된 형상입니다. **더블 클릭**으로 들어가 편집하고, `Esc`나 바깥 클릭으로 나옵니다. 편집하는 동안 모델의 나머지는 **흐려집니다**(카메라 ▸ 편집 시 모델의 나머지).
- **그룹 분해**(`Ctrl+Shift+G`)는 한 단계를 풉니다. **그룹 병합**은 여러 그룹을 하나로 합칩니다.
- **컴포넌트 만들기…**(`G`): 선택이 이름 있는 **정의**와 첫 인스턴스가 됩니다. 복사하면(`Ctrl+C`/`Ctrl+V`, 또는 `Ctrl`을 누른 채 이동) **정의를 공유하는** 인스턴스가 생깁니다: 하나를 고치면 모두 바뀝니다([자세히](organizacion.md#componentes-editas-uno-cambian-todos)). 인스턴스를 옮겨도 형상이 복제되지 않습니다.
- **고유하게 만들기**(오른쪽 클릭)는 사본 하나를 떼어 내 따로 편집하게 합니다.
- 복사·붙여넣기는 문서 사이에서도 됩니다. 붙여넣을 때 색과 텍스처가 입혀진 **솔리드 미리 보기**가 커서를 따라오고, 한 번만 찍힙니다.

## 실행 취소

`Ctrl+Z` / `Ctrl+Shift+Z`(또는 `Ctrl+Y`). **모든** 작업이 기록에 남습니다 — 가져오기 전체나 [AI](../ia.md)가 그린 것까지 언제든 되돌릴 수 있습니다. 기록은 기본 **200단계**이며 [환경 설정 ▸ 일반](../preferencias.md#general)에서 바꿉니다(0 = 제한 없음).
