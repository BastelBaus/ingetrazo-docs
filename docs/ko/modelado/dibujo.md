# 그리기 도구

모든 도구는 같은 방식으로 동작합니다: 클릭으로 시작하고, **추론**이 기존 형상에 맞춰 붙여 주며, **VCB**가 키보드로 정확한 치수를 받습니다(입력하고 Enter, 입력란을 클릭할 필요 없음).

## 선과 다각형

| 도구 | 단축키 | 사용법 |
|---|---|---|
| **선** | `L` | 클릭, 클릭으로 그립니다. 길이를 입력하면 정확한 구간이 됩니다. 윤곽을 닫으면 면이 저절로 생깁니다. |
| **사각형** | `R` | 두 모서리. `너비,높이`를 입력합니다(예: `6,4`). **`Ctrl`**로 **중심에서**(중심과 한 모서리) 모드로 바뀝니다: 연필 표시가 바뀌고, 입력한 `너비,높이`는 **전체** 크기입니다. 도구를 다시 잡으면 모서리 모드로 시작합니다. |
| **회전된 사각형** | `K` | 먼저 밑변(두 점), 그다음 높이. |
| **원** | `C` | 중심과 반지름. 반지름을 입력합니다. |
| **다각형** | — | 중심과 반지름. 변의 개수를 입력합니다(`G`는 컴포넌트 만들기입니다). |
| **자유 곡선** | — | 끌었다 놓습니다: 매끄러운 폴리라인이 되고, 원처럼 클릭 한 번으로 통째로 선택됩니다. 닫히면 면을 만듭니다. |

## 호

| 도구 | 단축키 | 사용법 |
|---|---|---|
| **호** | `A` | 양 끝점(현)을 찍고 그다음 볼록한 정도. 2점 호입니다. 볼록 높이를 입력하거나, 반지름은 `2r`처럼 입력합니다. **모서리 둥글리기**: 한 모서리 선 위에서 시작해, 이웃 모서리 선에서 꼭짓점으로부터 같은 거리에 오면 호가 **자홍색**(두 선 모두에 접함)으로 바뀝니다. 거기서 더블 클릭하면 호를 그리고 모서리를 잘라 냅니다. 호가 자홍색일 때 **입력한 숫자는 둥글리기 반지름**이 되며, 접선 조건은 유지됩니다. |
| **3점 호** | `J` | 끝점, 지나가는 점, 다른 끝점. |
| **중심 호** | `Shift+O` | 중심, 시작 반지름, 회전 범위. |
| **부채꼴** (Pie) | — | 중심 호와 같지만, 두 반지름과 면으로 부채꼴을 닫습니다. |

## 파생 도구

| 도구 | 단축키 | 사용법 |
|---|---|---|
| **간격 띄우기 (Offset)** | `F` | 면의 윤곽을 정확한 거리만큼 안쪽이나 바깥쪽으로 복사합니다. 벽 두께에 쓰는 대표 도구입니다. **모서리**에도 동작합니다: 떨어져 있는 모서리를 클릭하면 연결된 체인 전체(열린 것이든 닫힌 것이든)를 띄우고, 원하는 모서리들을 미리 선택한 뒤 그중 하나를 클릭해도 됩니다. |
| **따라가기 (Follow me)** | `W` | 프로파일을 경로를 따라 돌출합니다: 몰딩, 배관, 연석. |
| **3D 텍스트** | — | 그리기 ▸ 3D 텍스트: 실제 부피가 있는 글자(글꼴, 굵게, 기울임, 높이, 두께). 바로 돌출하거나 칠할 수 있습니다. |

### 따라가기, 세 가지 방법

프로파일을 **경로에 수직으로** 그리세요(가장 쉬운 방법: 면 위에 그리고 남는 모서리를 지웁니다).

1. **경로를 따라 끌기** — 따라가기(`W`)를 켜고 프로파일을 클릭한 뒤, 커서를 경로의 모서리에 닿게 하며 움직입니다: 경로가 **빨간색**으로 강조되고, 돌출 결과가 연귀 이음까지 실시간으로 미리 보입니다. 끝에 도달하면 클릭(끌고 있었다면 버튼을 놓기). `Esc`는 처음부터 다시 시작합니다. 호의 구간을 건너뛰면 그 사이의 연결된 모서리를 따라가고, 되돌아가면 경로가 짧아집니다.
2. **미리 선택한 경로** — 경로의 모서리를 선택하고(원의 한 구간을 클릭하면 윤곽 전체가 선택됨), 따라가기를 켜고 프로파일을 클릭하면 한 번에 돌출됩니다.
3. **면의 둘레** — 테두리가 경로인 면을 선택하고 프로파일을 클릭합니다. 또는 끄는 도중 면 위에서 `Alt`를 누르고 있으면 그 둘레를 씁니다. 슬래브 둘레의 몰딩이나 **회전체**(원을 경로로, 반 프로파일을 단면으로)를 만드는 지름길입니다.

## 키보드 치수 입력: 미터, 센티미터, 인치, 피트 { #medidas-por-teclado-metros-centimetros-pulgadas-pies }

접미사 없는 숫자는 **문서 단위**입니다([환경 설정 ▸ 단위](../preferencias.md#unidades)에서 바꾸지 않았다면 미터. 밀리미터 문서에서는 `500`이 0.5 m입니다). 입력란마다 자체 단위를 붙일 수 있어서, 같은 모델 안에서 목재나 배관은 인치로, 경간은 미터로 그릴 수 있습니다:

| 입력 | 값 |
|---|---|
| `3,2` | 3.20 m |
| `30cm` · `1500mm` | 0.30 m · 1.50 m |
| `2"` · `2in` | 2인치 |
| `1'` · `1ft` | 1피트 |
| `1'6"` | 1피트 6인치 |
| `3/4"` · `1'3/4"` | 인치 분수 |
| `1 1/2"` · `1-1/2"` · `1'6 1/2"` | 1과 1/2인치, 1피트 6과 1/2인치(대분수) |
| `2";4"` | 2 × 4인치 사각형 |
| `3,2;1'6";10cm` | 단위를 섞은 X, Y, Z 이동 |

따옴표와 분수 사선은 숫자 뒤에서만 받으므로, `I`와 `F`는 계속 도구 단축키로 쓰입니다.

**인치나 피트로 치수 기입.** 트레이의 치수 스타일(그리고 시트의 각 치수 패널)에서 단위를 고릅니다: `m`, `cm`, `mm`, `in`, `ft`, `ft-in`, 또는 분수형 `in-frac`(`1 1/2"`)와 `ft-in-frac`(`1'6 1/2"`). 분수형에서는 **소수 자릿수**가 가장 작은 분모를 정합니다: 0 = 정수 인치, 1 = 1/4, 2 = 1/16, 3 = 1/32, 4 = 1/64.

## 작업 평면

도구는 **지금 보고 있는 평면** 위에 그립니다: 위 뷰에서는 평면도로 그리고, 기존 면 위에서 시작하면 그 면 위에 그립니다. 추론 없이 찍은 첫 점은 현재 뷰의 평면에 놓입니다 — 그래서 선이 예상치 못한 깊이로 "튀어 나가는" 일이 없습니다.

**화살표 키로 평면 고정**(원, 다각형, 사각형, 호): 첫 클릭 전에 `→`는 X에 수직인 평면(YZ), `←`는 Y에 수직인 평면(XZ), `↑`는 Z에 수직인 평면(XY)을 고정합니다. 같은 화살표를 다시 누르거나 `Esc`를 누르면 해제되고, 축 색깔의 레이블이 상태를 알려 줍니다. 평면이 고정되어 있으면 중심이 면 위에 떨어져도 도형은 고른 평면에 그려집니다. 고정은 도형 하나에 쓰이고 나면 풀립니다. 첫 클릭 뒤에는 화살표가 평소의 축 고정으로 돌아갑니다.

**`↓`로 모서리에 수직**(자홍색 고정): 첫 클릭 전에 커서를 모서리 위에 두고 `↓`를 누르면 그리기 평면이 그 모서리에 수직으로 고정됩니다. 면 위라면 면에 평행으로 고정됩니다. 커서 고리가 자홍색이 되고, `↓`를 다시 누르면 풀립니다. 기울어진 축 위에 관을 그리는 방법입니다: 축 선을 그리고, 그 위에서 `↓`를 누르고, 원의 중심을 끝점에 두고, 반지름을 주고, 따라가기를 적용합니다. 원이 처음부터 축에 수직으로 그려지므로 나중에 회전할 필요가 없습니다.

!!! tip "표준 뷰에서 그리기"
    2D 같은 정밀 작업에는 **표준 뷰 + 평행 투영**(`P`)을 함께 쓰세요: 입면은 정면, 평면은 위. 화면에 보이는 치수가 원근 효과 없이 그 평면의 실제 치수입니다.

## 추론

그리는 동안 보이는 색깔 점:

- **초록** — 모서리 끝점.
- **청록** — 중점.
- **빨강/초록/파랑** — 좌표계 축 위(X 동쪽, Y 북쪽, Z 수직). **축 자석**(축에서 몇 도 이내의 선은 축에 붙음)은 선을 긋는 모든 도구에 있습니다: 선, 호, 원, 다각형, 회전된 사각형, 줄자, 각도기, 치수, 텍스트, 이동.
- **자홍** — 기존 모서리에 평행하거나 수직.

점 위에 마우스를 잠깐 올려 두면 그 점을 "기억"해 거기서부터 투영할 수 있습니다: 그 점과 축 방향으로 정렬되면 점에서 점선이 나타납니다(**점에서**).

그리고 **다른 벽**—수직인 벽이든 마주 보는 벽이든—에서 기억한 점의 높이를 지나면 커서가 그 높이로 벽을 가로지르는 점선에 붙습니다(**점의 높이에서**): 이렇게 하면 가이드 선 없이 집의 모든 창을 같은 높이에 놓을 수 있습니다. 바닥에서 높은 점 아래를 지날 때는 평면에서 같은 일이 일어납니다(**점과 일직선**).
