# 레이어, 장면, 정리

## 레이어

트레이의 **레이어** 패널은 모델의 표시 여부를 정리합니다(목록은 12줄까지 늘어나고, 그 뒤로는 컴포넌트 목록처럼 저절로 스크롤됩니다):

- **+ 레이어**로 하나를 만듭니다. 각 개체의 선택기(또는 개체 정보 패널)에서 레이어를 지정합니다.
- **눈** 아이콘은 그 레이어에 있는 모든 것 — 가구, 참조, 설비 — 을 표시하거나 숨깁니다.
- `.skp`를 가져오면 그 레이어/태그가 원래의 표시 상태 그대로 들어옵니다.
- 레이어를 삭제해도 형상은 지워지지 않고 기본 레이어로 옮겨집니다.

!!! note "레이어 = 표시, 분리가 아님"
    레이어는 무엇이 보일지를 정합니다. 서로 다른 레이어의 형상도 같은 공간에 있으면 **서로 붙습니다**. 형상을 분리하려면 **그룹**을 쓰세요.

## 장면

**장면** 패널은 이름 있는 뷰를 저장합니다:

- **+ 장면**은 현재 카메라**와** 어떤 레이어가 숨겨져 있는지를 함께 저장합니다.
- 장면을 **더블 클릭**하면 복원됩니다.
- 장면은 `.igz`에 저장되고, 가져온 `.skp`에서도 들어오며, [시트 레이아웃](../laminas/marcos.md)의 **뷰 소스**가 됩니다: 잘 준비한 "평면" 장면이 곧 평면도입니다.

## 개체 정보

**정보** 패널은 선택 항목의 핵심을 보여 주고 편집합니다: 모서리 길이, 면 면적, 레이어, 재질, 그리고 BIM 메타데이터가 있다면 그것까지.

## 장면이 기억하는 것

카메라와 레이어 외에도, 장면마다 활성 **스타일**, 활성 **단면 평면**과 절단 표시 여부, 그림자의 **태양 시각**을 저장합니다. `F2`는 목록에서 선택한 장면(또는 레이어)의 이름을 바꾸고, **업데이트**는 현재 뷰로 다시 저장합니다.

## 시각 스타일, 단면, 그림자

- **스타일**(기본, 건축, 숨은선, X-ray… 그리고 내가 만든 것), **실제 태양의 그림자**, 깨끗한 화면은 별도 페이지가 있습니다: [스타일, 그림자, 화면](estilos-sombras.md).
- **단면 평면**은 안을 들여다보도록 모델을 자릅니다: [단면 평면](secciones.md).
- 따라 그릴 스캔 도면이나 사진: [참조 이미지](imagenes-referencia.md).
- **면 컬링**: 뒷면을 회청색으로 칠해 뒤집힌 면을 한눈에 찾게 합니다.
- 파일 ▸ 내보내기 ▸ **이미지**는 뷰포트를 고해상도로 캡처해 저장합니다.

## 컴포넌트: 하나를 고치면 모두 바뀝니다 { #componentes-editas-uno-cambian-todos }

컴포넌트의 사본(Ctrl+C / Ctrl+V, 또는 Ctrl을 누른 채 이동)은 같은 정의를 공유합니다:

- **아무 사본이나 더블 클릭**하면 편집하도록 열립니다. 안에서 그리고, 밀고, 지운 뒤 나오면(Esc 또는 바깥 클릭) 변경이 **모든** 사본에 적용됩니다. 편집 전체가 Ctrl+Z 한 번으로 되돌아갑니다.
- **바깥에서 사본에 밀기/끌기**를 해도 정의가 편집됩니다: 다른 사본도 똑같이 밀립니다.
- **사본 하나만 바꾸려면** 편집하기 전에 오른쪽 클릭 ▸ **고유하게 만들기**: 그 사본이 떨어져 나오고 나머지는 계속 정의를 공유합니다.
- 컴포넌트 안을 들여다보고 아무것도 건드리지 않고 나오면 아무것도 바뀌지 않습니다.
- **컴포넌트 만들기…**(`G`)는 선택을 이름 있는 정의로 바꾸고, **그룹 병합**은 여러 그룹을 하나로 합치며, **그룹 분해**(`Ctrl+Shift+G`)는 한 단계를 풉니다.
- **하위 그룹**이 있는 `.skp` 컴포넌트를 가져오면 계층이 유지됩니다: 하나의 객체처럼 이동·복사되고 파일도 커지지 않습니다. 그 안을 편집하면 그 문서에서는 계층이 풀립니다(중첩 컴포넌트를 편집할 때의 일반적인 동작).
