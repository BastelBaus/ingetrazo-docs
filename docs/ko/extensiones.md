# 확장 기능

**0.3.2** 버전부터 IngeTrazo는 **플러그인**으로 확장할 수 있습니다: 앱을 건드리지 않고
새 도구를 추가하는 작은 프로그램입니다. 모든 것이 상단 메뉴 막대의 **확장 기능** 메뉴에
있습니다.

여러 확장 기능이 기본으로 들어 있습니다: **모델 정보**, **Python 콘솔**,
**솔리드 검사기**, 그리고 — 0.3.5 버전부터 — **AI 도우미**와
**AI 브리지 (MCP)**([AI로 모델링하기](ia.md)).

## 모델 정보

**확장 기능 ▸ 모델 정보**는 문서 전체를 엑스레이처럼 들여다보는 창을 세 탭으로
엽니다:

- **형상** — 꼭짓점, 모서리, 면, 삼각형(전체, 떨어진 형상, 그룹), 문서 단위로 된
  **경계 상자**, 그리고 주석 개수(치수, 텍스트, 가이드, 장면, 경로).
- **재질 및 레이어** — 쓰이는 재질마다 **몇 개의 면에 쓰였고 몇 m²를 칠하는지**
  (마감 물량에 바로 쓰는 데이터), 그리고 표시·잠금 상태가 있는 레이어 목록.
- **BIM** — IFC 클래스가 붙은 객체와 그 **면적과 부피**. BIM 패널과 `.ifc`
  내보내기와 같은 숫자입니다: 레이블 하나가 붙은 여섯 면짜리 벽은 여섯 개가 아니라
  **하나**의 객체로 셉니다.

![실제 프로젝트 파일에 대한 모델 정보](images/extensiones-info-del-modelo.png)

**클립보드에 복사** 버튼은 요약을 일반 텍스트로 내보내, 보고서나 메일에 바로
붙여 넣을 수 있게 합니다.

!!! tip "숫자는 거짓말하지 않습니다"
    모델 정보는 프로그램의 다른 부분과 같은 소스를 읽습니다. 대화 상자에
    IfcWall 3개, 45 m²라고 나오면, 정확히 그것이 `.ifc` — 그리고
    [IngePresupuestos](https://ingepresupuestos.com) — 에 도착합니다.

## Python 콘솔

**확장 기능 ▸ Python 콘솔**(또는 `Ctrl+Shift+P`)은 **열린 모델 위에서 실시간으로**
동작하는 프로그래밍 콘솔을 엽니다. 고급 사용자를 위한 도구입니다: 모델 검사,
코드로 형상 생성, 반복 작업 자동화.

코드를 한 줄도 쓰지 않더라도 알아 둘 것:

- **스크립트가 만든 모든 것은 실행 취소 한 단계입니다.** (모델 창이 활성일 때)
  `Ctrl+Z`가 다른 편집처럼 통째로 없앱니다.
- **실패한 스크립트는 아무것도 반쯤 남기지 않습니다**: 문서가 저절로 이전 상태로
  돌아가고, 콘솔이 오류를 빨간색으로 보여 줍니다.
- 변경은 문서를 **수정됨**으로 표시합니다 — 저장하지 않고 닫으면 IngeTrazo가
  평소처럼 알려 줍니다.

코드 한 줄 없이 동작하는 모습을 보고 싶나요? **"파일 실행…"** 버튼을 누르고
`scripts/create_architectural_showcase.py`(프로그램에 포함)를 고르세요: 슬래브,
기둥, 벽, 지붕이 있는 작은 정자를 **BIM 레이블까지 모두 붙여** 만듭니다 — 그리고
`Ctrl+Z` 한 번으로 되돌아갑니다. **"API 도움말"** 버튼은 쓸 수 있는 객체와 시작용
코드 조각을 보여 줍니다.

![콘솔에서 방금 만든 예제 스크립트의 정자](images/extensiones-consola-pabellon.png)

## 솔리드 검사기

**확장 기능 ▸ 솔리드 검사기**는 그룹이 왜 밀폐된 솔리드(3D 프린팅 가능, 부피 측정
가능)가 아닌지 진단합니다: 문제가 있는 모서리 — 열린 가장자리, 세 개 이상의 면에 걸친
모서리 — 를 하나하나 나열하고, 한눈에 찾도록 뷰포트에서 강조합니다.

## AI 도우미와 AI 브리지 (MCP)

**AI로 모델링하는** 두 방법은 별도 페이지가 있습니다: [AI로 모델링하기](ia.md). 요약하면:

- **확장 기능 ▸ AI 도우미**(`Ctrl+Shift+A`): IngeTrazo 안의 채팅으로, 원하는 것을 설명하거나 —사진을 첨부해— 고른 제공자의 키로 요청합니다(무료 Groq, Gemini, OpenAI, Anthropic, OpenRouter, DeepSeek, 로컬 Ollama).
- **확장 기능 ▸ AI 브리지 (MCP)**: Model Context Protocol을 쓰는 에이전트라면 누구든(Claude Code, Claude Desktop, Cursor, VS Code, Gemini CLI, Codex CLI…) 열린 앱을 조종합니다. 패키지에 서버가 들어 있고(Windows는 `ingetrazo-mcp.exe`, Linux는 `ingetrazo --mcp`) 메뉴가 연결에 필요한 정확한 명령 줄을 알려 줍니다.

두 경우 모두 작업 하나가 **실행 취소 한 단계**이고, 실패하면 문서 전체가 되돌아갑니다 — Python 콘솔과 같은 보장입니다.

## 다른 사람이 만든 확장 기능 설치

확장 기능은 `.py` 파일입니다. 개인 플러그인 폴더에 복사하고
(**확장 기능 ▸ 플러그인 폴더 열기**가 폴더를 만들고 열어 줍니다) IngeTrazo를
다시 시작하세요:

=== "Linux"

    ```
    ~/.local/share/ingetrazo/plugins/
    ```

=== "Windows"

    ```
    %APPDATA%\ingetrazo\plugins\
    ```

플러그인의 도구는 **확장 기능** 메뉴에 나타납니다. 플러그인에 오류가 있어도
**IngeTrazo는 그대로 열립니다**: 항목이 `⚠ 이름 (불러오기 오류)`처럼 회색으로
나타나고, 마우스를 올리면 작성자에게 알릴 정확한 오류가 보입니다. 제거하려면
파일을 지우세요.

!!! warning "믿을 수 있는 확장 기능만 설치하세요"
    플러그인은 IngeTrazo와 같은 권한으로 코드를 실행합니다: 내 파일을 읽고 쓸 수
    있습니다. Blender나 다른 프로그램의 확장 기능과 같은 신뢰 관계입니다 — 아는
    출처에서 온 것만 설치하세요.

## 나만의 확장 기능 만들기

Python으로 프로그래밍한다면, 개발자 가이드(영어)가 저장소에 있습니다 —
**확장 기능 ▸ 플러그인 개발…**이 바로 엽니다:
[`docs/plugins.md`](https://github.com/ingelibre/ingetrazo/blob/main/docs/plugins.md)
— 최소 예제는 약 10줄이며, Python 콘솔이 자연스러운 시험대입니다: 콘솔에서
동작하는 것은 플러그인에서도 동작합니다.

기본 제공 확장 기능의 코드는 모두 자유 소프트웨어(GPL-3.0)이며 저장소의
[`plugins/`](https://github.com/ingelibre/ingetrazo/tree/main/plugins) 폴더에
있습니다 — AI 도우미 자체도 플러그인이라 완전한 예제가 됩니다. 기여를 환영합니다:
확장 기능 엔진 자체가 커뮤니티의 기여에서 태어났습니다.

!!! note "API는 아직 안정되지 않았습니다"
    0.x 시리즈 동안에는 플러그인 시스템이 버전마다 바뀔 수 있습니다.
    오늘 공개한 확장 기능이 다음 버전에서 손봐야 할 수도 있습니다.
