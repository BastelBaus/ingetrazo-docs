# 프로젝트 위치와 배경 지도

모든 지형 작업은 프로젝트가 **어디에** 있는지 정하는 데서 시작합니다. 그것이 좌표계를 고정하고 위성 지도, 3D 지형, 현장 데이터를 쓸 수 있게 합니다.

## 위치 정하기

트레이의 **지형 / 기본 지도** 패널에서:

1. **위치 검색…**은 위치 찾기를 엽니다: 이름으로 장소를 찾거나, "내 위치"를 쓰거나, 지도를 둘러봅니다.
2. **가운데 핀이 정확히 현장 위에 올 때까지** 지도를 맞춥니다 — 마음껏 확대하세요.
3. 확인한 다음 **위치로 이동**.

!!! warning "핀이 곧 모델의 원점입니다"
    고른 점이 모델의 **원점 (0,0,0)**이 됩니다. 원점 주위에 그리면 모델이 위성 지도 위의 정확한 자리에 놓입니다 — 나중에 옮길 필요가 없습니다. 지도 자체에도 핀이 *원점 (0,0)*으로 표시됩니다.

    프로젝트에 이미 위치가 있는데 다른 곳을 고르면, IngeTrazo는 **원점을 옮기기 전에 묻습니다**(그려 둔 것은 모두 로컬 좌표를 유지한 채 지도 위에서 다시 배치됩니다).

## 좌표: UTM 또는 지리 좌표

**좌표** 선택기로 위치를 어떻게 보고 입력할지 고릅니다 — 프로그램이 선택을 기억합니다:

- **UTM WGS84**: 존, 반구, **동향(E)**과 **북향(N)** — 드론이나 토털 스테이션이 보고하는 그대로, 표준 규약(가상 동향 500 km, 남반구 가상 북향 10 000 km)을 따릅니다.
- **지리 좌표**: 십진 도 단위의 위도와 경도.

두 좌표계는 내부적으로 항상 동기화되어 있어, 모드를 바꿔도 잃는 것이 없습니다. 프로젝트가 지리 참조되어 있으면 **상태 표시줄에 커서의 UTM 좌표가 실시간으로** 표시됩니다.

## 북쪽: 모델이 아니라 지도를 돌리세요

건물이나 광장은 **축(빨강과 초록)에 직각으로** 그립니다: 그래야 정면, 오른쪽, 왼쪽 뷰, 축 고정, 사각형이 생각할 필요 없이 동작합니다. 그런데 현장이 북쪽을 향하는 일은 드뭅니다. 위성 지도에 맞추려고 모델을 돌리면 그 모든 것을 잃습니다.

모델은 자기 축에 그대로 두고 **지도가 아래에서 돕니다**. 패널의 **북쪽** 입력란은 진북이 어느 쪽인지, 초록 축에서 시계 방향 각도로 알려 줍니다(0° = 초록 축이 북쪽을 가리킴). 값을 바꾸면 기본 지도, 3D 지형, 가져온 경로와 점, 그림자가 돌고, 모델은 움직이지 않습니다.

**이미 모델을 돌리고 끌어서 지도 위에 맞췄나요?** 모델을 선택하고(최상위 컴포넌트 하나여야 합니다 — 필요하면 그룹으로 묶으세요) **지도 위의 모델 바로 세우기**를 누르세요: 모델이 자기 축으로 돌아가고, 원점이 모델의 모서리로 옮겨지고, 북쪽 각도가 계산되어, **지도 위에서는 아무것도 움직이지 않습니다**. 저장된 장면, 치수, 모델에 고정된 시트도 함께 따라갑니다. 실행 취소 한 단계입니다.

!!! note "높이"
    바로 세우면 모델은 그려졌을 때의 높이를 되찾고, 지도는 z = 0(기준면)에 그대로 있습니다. 모델이 지도 위에 떠 있었다면 제자리로 내려옵니다.

## 기본 지도

- **소스**: Esri 위성, OpenStreetMap, 그리고 직접 추가한 것 — 어떤 **XYZ** 타일 서버든(예: QGIS로 서비스하는 나만의 정사영상) 이름을 붙여 저장하면 메뉴에 계속 남습니다.
- **캡처 영역**: 위치 찾기에서 사각형을 그릴 수 있습니다 — 현장이면 정사각형, 도로면 긴 띠.
- **줌**은 타일의 상세도를 정합니다. 아주 큰 캡처는 프로그램이 매끄럽게 돌도록 상세도를 자동으로 낮춥니다.
- 지도는 **시각적 참조일 뿐**입니다: 형상이나 물량에 절대 들어가지 않으며, 캡처 정보는 문서와 함께 저장됩니다(타일은 열 때 다시 내려받습니다).
