# 가져오기와 내보내기

## 기본 형식: `.igz`

열려 있고 문서화된 형식입니다. 텍스처가 없으면 읽을 수 있는 JSON이고, 텍스처가 있으면 자기 완결적 컨테이너가 됩니다(이미지가 내 컴퓨터의 경로 없이 **안에** 들어갑니다). 시트 구성, 레이어, 장면, 단면, 그림자, BIM, 지리 참조도 모두 여기에 저장됩니다. 원자적 저장: 정전이 나도 파일이 망가지지 않고, [환경 설정](preferencias.md)의 `.igz.bak` 백업이 있으면 디스크가 가득 찬 상황도 견딥니다. 더 새로운 버전의 `.igz`도 이전 버전에서 열립니다(모르는 부분은 무시).

## `.skp` 가져오기 — 기본 지원

![방금 연 `.skp`: 형상, 재질, 원래 레이어가 그대로 들어옵니다.](images/importar.jpeg)


**파일 ▸ 가져오기 ▸ SKP (.skp)…**, 또는 파일을 **더블 클릭**하거나, 창으로 끌어다 놓습니다.

가져오기 기능은 **자체 제작한 오픈 소스**입니다(IngeTrazo가 기여하는 [OpenSKP](https://github.com/iamahsanmehmood/openskp) 프로젝트): **변환기나 다른 프로그램을 설치하지 않고** `.skp`를 직접 읽으며, 예전 형식(2013–2020)부터 현재 형식까지 모든 세대를 지원합니다.

들어오는 것:

- 형상 전체, **그룹과 컴포넌트**(인스턴스는 계속 공유됨: 가로등 하나를 옮겨도 나머지가 끌려가지 않고, 중첩 컴포넌트는 계층을 유지).
- **재질과 텍스처**: 색을 입힌 재질, 반투명, 면별 재질, 위치가 지정된 텍스처, «항상 정면» 빌보드 포함.
- 표시 상태가 유지되는 **레이어/태그**, **장면**(장면별 카메라 + 레이어), **선형 치수**, **지시선 텍스트**.
- 실제 프로젝트 파일로 검증: 경계 상자가 정확하고, 원본 모델과의 면적 차이가 0.00 %.

## CAD: DXF와 DWG { #cad-dxf-y-dwg }

**파일 ▸ 가져오기 ▸ AutoCAD DXF (.dxf)…** 또는 **AutoCAD DWG (.dwg)…**는 CAD의 2D·3D 도면을 가져옵니다:

- 각 **레이어**는 레이블이 붙은 그룹으로, **곡선**(호, 원, 폴리라인)은 클릭 한 번에 선택되는 단일 개체로, **블록**은 인스턴스가 있는 컴포넌트로, 3D 면은 동일 평면 면을 합친 면으로 들어옵니다. 텍스트와 치수는 빠집니다.
- **단위는 도면을 측정해 제안합니다**(DWG 헤더는 틀린 경우가 많음). 대화 상자에서 확인할 수 있습니다. 멀리 떨어진 UTM 좌표는 저절로 중심으로 옮겨집니다.
- DWG는 Linux 패키지에 들어 있는 LibreDWG로 변환합니다(Windows에서는 당분간 CAD에서 DXF로 내보내세요).
- `.dxf`나 `.dwg`를 더블 클릭해도 열립니다.

반대 방향은 [시트의 뷰를 DXF로 내보내기](laminas/exportar.md#dxf-hacia-ingecad-autocad)를 참고하세요.

## 기타 형식

| 형식 | 가져오기 | 내보내기 | 메모 |
|---|:-:|:-:|---|
| **COLLADA (.dae)** | ✔ | ✔ | 내보내기에 지리 위치가 포함됨 — Blender가 현장의 태양과 함께 열어 일조 분석에 씁니다. |
| **OBJ** | ✔ | ✔ | 재질(MTL) 포함. 가져올 때 단위를 묻습니다. |
| **glTF / GLB** | ✔ | ✔ | 텍스처와 계층을 지원하는 기본 가져오기, PBR + 지리 위치 내보내기 — 웹 뷰어와 최신 Blender의 형식. |
| **STL** | — | ✔ | 바이너리, 3D 프린팅용. 밀폐된 솔리드 보장. |
| **IFC 4** | — | ✔ | BIM 브리지. [BIM과 물량 산출](bim.md) 참고. |
| **DXF (R12)** | ✔ | ✔ | CAD 도면으로 들어오고, 시트의 벡터 뷰로 나가며 선 종류마다 레이어 하나. |
| **DWG** | ✔ | — | LibreDWG 경유(Linux). |
| **이미지** | ✔ | ✔ | 따라 그릴 [참조 이미지](modelado/imagenes-referencia.md)로 들어오고, 뷰포트의 고해상도 캡처로 나갑니다. |
| **WebODM/ODM** | ✔ | — | 드론 측량. [지형](terreno/dron.md) 참고. |
| **측량 CSV** | ✔ | — | 토털 스테이션의 P,N,E,Z 점. [지형](terreno/rutas-perfil.md) 참고. |
| **KML / GeoJSON** | ✔ | — | 지리 참조된 선형과 다각형. |
| **PDF** | — | ✔ | 벡터 시트. [PDF 내보내기](laminas/exportar.md) 참고. |

모든 가져오기는 **실행 취소 한 단계**입니다: `Ctrl+Z`로 통째로 없앱니다.
